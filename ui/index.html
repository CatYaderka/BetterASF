Поведение приложения

Настройки самого BetterASF. Они сохраняются в Documents\BetterASF\settings.json.

Эти AppID применяются к каждому аккаунту отдельно: если игра есть в библиотеке — она запускается, если нет — пропускается. После них список дополняется играми по часам.

Steam Web API ключ

Для подбора игр по количеству часов нужен бесплатный Steam Web API ключ. Получите его на steamcommunity.com/dev/apikey (в поле домена впишите любое, напр. localhost). Ключ хранится локально.

Пароль IPC

ASF защищён паролем (IPCPassword). Введите его, чтобы подключиться.

# BetterASF

**Красивый, современный и по-настоящему удобный интерфейс для [ArchiSteamFarm](https://github.com/JustArchiNET/ArchiSteamFarm) — прямо на вашем рабочем столе.**

</div>

---

## 🌸 Что такое BetterASF?

Если вам надоело каждый раз открывать браузер для управления своей фермой Steam-аккаунтов, возиться со сложными конфигами в блокноте или смотреть на невзрачную консоль — этот проект создан для вас. 

**BetterASF** объединяет мощь ArchiSteamFarm и удобство нативного Windows-приложения. Он запускает ASF в скрытом фоновом режиме и выводит управление в красивое, быстрое окно с современным дизайном. Больше никакого браузера, никаких лишних вкладок и сложных JSON-файлов!

---

## ✨ Реальные возможности программы

Программа делает именно то, что заявлено ниже — без преувеличений и лишней "воды":

* 🖥️ **Нативное окно Edge WebView2** — приложение работает в собственном окне на базе встроенного в Windows 10/11 движка Edge. Оно быстрое, лёгкое и не требует открытия сторонних браузеров.
* 🎨 **4 потрясающие темы оформления** — выбирайте то, что нравится именно вам, во вкладке **«Настройки»**:
  * *Тёмная тема (Стандартная)* — строгий и стильный чёрный минимализм в стиле Steam.
  * *Светлая тема (Стандартная)* — аккуратное и чистое светлое оформление.
  * *Тёмная тема с (Dead Dream)* — эффектное полупрозрачное оформление с красивым неоновым аниме-артом на фоне и эффектом размытия заднего плана (Glassmorphism / Blur), напоминающим дизайн Windows 11 Fluent Design.
  * *Светлая тема (Dead Dream)* — элегантный светлый стиль с изящными тёмными контурными линиями на фоне.
* ⚙️ **Визуальное управление ботами** — добавляйте, настраивайте и удаляйте аккаунты прямо из интерфейса. Все опции (активный обмен, режим фарма, онлайн-статус, лимиты времени, ключи) настраиваются галочками и списками, избавляя вас от необходимости редактировать JSON вручную.
* 🔐 **Удобный Steam Guard / 2FA** — если вашему аккаунту требуется код подтверждения, приложение выведет красивое всплывающее окно прямо по центру экрана, где вы сможете ввести код или подтвердить вход через мобильное приложение Steam.
* ⌨️ **Встроенная консоль команд** — отправляйте любые команды для ASF (`status`, `stats`, `addlicense`, `help`) прямо из удобного текстового поля с готовыми кнопками-подсказками для самых частых команд.
* 📊 **Вся статистика перед глазами** — на боковой панели всегда отображается статус вашей фермы: количество ботов в сети/офлайне/на фарме, потребление оперативной памяти процессом ASF, аптайм работы программы и текущая версия.
* 🔌 **Список установленных плагинов** — во вкладке «Плагины» вы можете мгновенно посмотреть все загруженные расширения ASF и их точные версии.

## 🚀 Быстрый старт

> Для работы исходного кода вам понадобится **Python 3.10 или новее** ([скачать с официального сайта](https://www.python.org/)). При установке обязательно отметьте галочку **«Add Python to PATH»**.

### Шаг 1. Установите зависимости
Откройте терминал в папке проекта и выполните команду:
```bash
pip install -r requirements.txt
```

### Шаг 2. Добавьте ArchiSteamFarm
Положите файлы вашего `ArchiSteamFarm.exe` рядом со скриптами (или укажите к нему индивидуальный путь в файле `config.ini` в строке `asf_path = `).

### Шаг 3. Запустите приложение
Просто дважды кликните по файлу:
* **`Run-ASF-Desktop.bat`** — для обычного, чистого запуска.
* **`Debug-Run.bat`** — если что-то идёт не так (запустит программу с открытой консолью разработчика и подробным выводом логов в файл `debug-log.txt`).

## ⚙️ Настройки приложения (`config.ini`)

Файл `config.ini` содержит простые и понятные параметры для тонкой настройки лаунчера под себя:

* `asf_path` — путь к файлу `ArchiSteamFarm.exe` (оставьте пустым, если он лежит в папке программы).
* `start_asf` (`true`/`false`) — запускать ли сам ASF при открытии окна (если вы хотите запускать ASF отдельно, поставьте `false`).
* `theme` (`dark`/`light`) — начальная тема оформления (последний выбор пользователя в интерфейсе запоминается автоматически).
* `frameless` (`true`/`false`) — включить кастомную безрамочную шапку окна с кнопками управления в стиле Windows 11 (`true`) или оставить стандартную системную рамку (`false`).
* `window_width` и `window_height` — размеры окна при первом открытии.

## 📦 Сборка в один файл (`.exe`)

Вы можете упаковать всё приложение со всеми скриптами, оформлением и встроенным ASF в **один портативный исполняемый файл**:

1. (Опционально) Распакуйте файлы вашей сборки ASF (для Windows x64) прямо в папку `_asf`.
2. Дважды кликните на файл **`build_exe.bat`**.
3. После завершения сборки в папке `dist/` появится файл `BetterASF.exe`. Вы можете переносить его куда угодно!

## 🛠️ Создание установщика

В репозиторий встроен конфигурационный файл для [Inno Setup](https://jrsoftware.org/isdl.php) (`installer.iss`), который позволяет в один клик собрать полноценный профессиональный установщик, устанавливающий BetterASF в папку `Program Files`, создающий ярлыки на рабочем столе и хранящий ваши аккаунты в безопасной папке `Документы/BetterASF`.

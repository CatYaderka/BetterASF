# BetterASF

**Русский** · [English](README.en.md) · [Українська](README.uk.md)

BetterASF — desktop-интерфейс для [ArchiSteamFarm](https://github.com/JustArchiNET/ArchiSteamFarm) под Windows. Он запускает ASF в фоне и собирает управление ботами, фармом, плагинами и настройками в одном окне WebView2.

## Возможности

### Управление ASF

- запуск ASF вместе с приложением;
- отслеживание IPC и статуса соединения;
- ожидание self-update ASF без автоматического удаления runtime;
- запись диагностики запуска в `debug-log.txt` и `asf-launch.log`;
- перезапуск и проверка обновлений ASF из настроек;
- сворачивание в трей, запуск в свёрнутом виде и автозапуск Windows.

### Боты

- создание, редактирование и удаление конфигов ботов;
- компактные карточки аккаунтов на вкладке «Боты»;
- отдельное окно профиля аккаунта;
- кнопки настроек, старта/паузы и включения/отключения;
- список текущих игр с названиями и обложками Steam, включая игры фарма часов;
- массовая статистика сети, фарма, памяти и аптайма.

### Steam Guard и вход

- обработка пароля, Steam Guard, 2FA, родительского кода и подтверждения входа;
- кнопка «Позже» без повторного немедленного открытия окна;
- жёлтый мигающий пункт «Запросы на вход» под настройками;
- журнал новых событий в выбранном языке интерфейса.

### Фарм карточек и часов

- фоновый Python-сервис фарма часов, не зависящий от состояния WebView2;
- автоматический фарм часов после окончания фарма карточек;
- запуск фарма часов при старте BetterASF;
- отдельный лимит числа игр для каждого аккаунта;
- приоритетные AppID для каждого аккаунта;
- порядок по возрастанию и убыванию часов;
- режим популярных игр из актуального Steam-топа по онлайну;
- автоматический возврат к фарму карточек, когда у аккаунта появляется очередь игр с карточками;
- повторное применение фарма часов после восстановления соединения.

### Плагины

- библиотека установленных плагинов ASF;
- отображение настоящего имени плагина через ASF `IPlugin.Name`;
- fallback-распознавание встроенных официальных плагинов;
- установка и удаление ZIP-релизов из GitHub;
- подтверждение удаления;
- безопасная распаковка с ограничением размера и защитой от path traversal;
- каталог из `plugin_catalog.json`, который проверяется через HTTP ETag.

### Интерфейс

- Русский, English и Українська;
- светлая и тёмная стандартные темы;
- темы Dead Dream;
- своя тема: светлая/тёмная основа, PNG/JPG/WebP/GIF/MP4/WebM-фон и прозрачность интерфейса;
- экономичный режим интерфейса;
- журнал действий, контекстное меню ботов и локальная страница диагностики.

## Быстрый запуск из исходников

Требуется Windows 10/11, Python 3.10+, Edge WebView2 Runtime и ASF.

```bat
python -m pip install -r requirements.txt
python asf_desktop.py
```

Дополнительные сценарии:

```text
Run-ASF-Desktop.bat  обычный запуск
Debug-Run.bat        запуск с консолью и диагностикой
```

## Сборка

На Windows:

```bat
build_exe.bat
```

Результат:

```text
dist\BetterASF.exe
```

При первом запуске `.exe` устанавливается в:

```text
Program Files\BetterASF
```

Ярлыки создаются на Рабочем столе и в меню «Пуск».

## Данные пользователя

Пользовательские данные не хранятся рядом с `.exe`:

```text
Documents\BetterASF\config\                  конфиги ботов
Documents\BetterASF\ASF-runtime\             runtime ASF
Documents\BetterASF\settings.json             настройки BetterASF
Documents\BetterASF\custom-theme-image.*      фон своей темы
Documents\BetterASF\steam-app-index.json        локальный каталог названий Steam
Documents\BetterASF\steam-covers\              кэш обложек Steam
Documents\BetterASF\plugin-catalog-cache.json кэш каталога плагинов
Documents\BetterASF\debug-log.txt             журнал BetterASF
Documents\BetterASF\asf-launch.log            вывод запуска ASF
```

Чтобы вшить ASF в сборку, до запуска `build_exe.bat` поместите содержимое Windows-релиза ASF в `_asf`, чтобы существовал файл:

```text
_asf\ArchiSteamFarm.exe
```

## Каталог плагинов

Список разрешённых источников хранится в:

```text
plugin_catalog.json
```

При открытии магазина BetterASF условно загружает этот файл из ветки `main` репозитория через ETag. Метаданные релизов не обновляются, если сам каталог не изменился.

Плагины исполняются внутри процесса ASF. Устанавливайте только проекты, которым доверяете.

## Безопасность

- Steam-пароли и 2FA-файлы остаются в модели конфигурации ASF;
- BetterASF не загружает произвольные ссылки как плагины: установка ограничена каталогом;
- сторонние ошибки Steam, ASF и GitHub отображаются как получены от источника;
- перед использованием готовой сборки рекомендуется проверить исходники и содержимое `_asf`.

# BetterASF

[Русский](README.ru.md) · [English](README.en.md) · **Українська**

BetterASF — desktop-інтерфейс для [ArchiSteamFarm](https://github.com/JustArchiNET/ArchiSteamFarm) у Windows. Він запускає ASF у фоні та об’єднує керування ботами, фарм, плагіни й налаштування в одному вікні WebView2.

## Можливості

### Керування ASF

- Запуск ASF разом із BetterASF.
- Контроль IPC і стану з’єднання.
- Очікування replacement-процесу після самооновлення ASF без видалення runtime.
- Журнали запуску `debug-log.txt` і `asf-launch.log`.
- Перезапуск ASF і перевірка оновлень ASF у налаштуваннях.
- Трей, запуск у згорнутому стані та автозавантаження Windows.

### Боти

- Створення, редагування та видалення конфігурацій ботів.
- Компактні картки акаунтів у вкладці «Боти».
- Окреме вікно профілю акаунта.
- Кнопки Налаштування, Старт/Пауза та Увімкнути/Вимкнути.
- Поточні ігри з назвами та обкладинками Steam, включно з іграми фарму годин.
- Загальна статистика мережі, фарму, пам’яті й аптайму.

### Steam Guard і вхід

- Підтримка пароля, Steam Guard, 2FA, батьківського коду та підтвердження входу.
- Кнопка «Пізніше» відкладає запит без негайного повторного відкриття.
- Жовтий пункт «Запити на вхід», що блимає, під Налаштуваннями.
- Нові локальні рядки журналу пишуться вибраною мовою інтерфейсу.

### Фарм карток і годин

- Фоновий Python-сервіс фарму годин, незалежний від WebView2.
- Фарм годин після завершення фарму карток.
- Запуск фарму годин разом із BetterASF.
- Окремий ліміт ігор для кожного акаунта.
- Пріоритетні AppID для кожного акаунта.
- Порядок за зростанням або спаданням годин.
- Режим актуальних популярних ігор Steam.
- Повернення ASF до фарму карток, коли в акаунта з’являється черга ігор із картками.
- Повторний запуск фарму годин після відновлення з’єднання, коли це доречно.

### Плагіни

- Бібліотека встановлених ASF-плагінів.
- Справжня назва плагіна з ASF `IPlugin.Name`.
- Розпізнавання вбудованих офіційних плагінів, коли ASF IPC недоступний.
- Встановлення та видалення GitHub ZIP-релізів.
- Підтвердження видалення і перезапуск ASF для застосування змін.
- Безпечне розпакування з обмеженням розміру та захистом від path traversal.
- Оновлюваний `plugin_catalog.json` через HTTP ETag.

### Інтерфейс

- Російська, English та Українська.
- Стандартні темна й світла теми.
- Теми Dead Dream.
- Власна тема: темна/світла основа, PNG/JPG/WebP/GIF/MP4/WebM-медіафон і прозорість інтерфейсу.
- Економний режим, журнал подій і контекстне меню ботів.

## Швидкий запуск із вихідного коду

Потрібні Windows 10/11, Python 3.10+, Edge WebView2 Runtime та ASF.

```bat
python -m pip install -r requirements.txt
python asf_desktop.py
```

Додаткові сценарії:

```text
Run-ASF-Desktop.bat  звичайний запуск
Debug-Run.bat        запуск із діагностикою
```

## Збірка

У Windows:

```bat
build_exe.bat
```

Результат:

```text
dist\BetterASF.exe
```

Під час першого запуску `.exe` встановлюється в:

```text
Program Files\BetterASF
```

Ярлики Робочого столу та меню «Пуск» створюються автоматично.

## Дані користувача

Дані зберігаються поза `.exe`:

```text
Documents\BetterASF\config\                  конфігурації ботів
Documents\BetterASF\ASF-runtime\             runtime ASF
Documents\BetterASF\settings.json             налаштування BetterASF
Documents\BetterASF\custom-theme-image.*      фон власної теми
Documents\BetterASF\steam-app-index.json        локальний каталог назв Steam
Documents\BetterASF\steam-covers\              кеш обкладинок Steam
Documents\BetterASF\plugin-catalog-cache.json кеш каталогу плагінів
Documents\BetterASF\debug-log.txt             журнал BetterASF
Documents\BetterASF\asf-launch.log            вивід запуску ASF
```

Щоб вбудувати ASF, перед `build_exe.bat` помістіть Windows-реліз ASF у `_asf`, щоб існував файл:

```text
_asf\ArchiSteamFarm.exe
```

## Каталог плагінів

Дозволені джерела плагінів містяться в:

```text
plugin_catalog.json
```

Під час відкриття магазину BetterASF умовно завантажує файл із гілки `main` через ETag. Дані релізів не оновлюються, доки сам каталог не змінився.

ASF-плагіни виконують код усередині процесу ASF. Встановлюйте лише проєкти, яким довіряєте.

## Безпека

- Паролі Steam і 2FA-файли залишаються в моделі конфігурації ASF.
- Встановлення плагінів обмежене каталогом, а не довільними URL.
- Помилки від Steam, ASF і GitHub показуються мовою джерела.
- Перед довірою до готового `.exe` перевіряйте вихідний код і файли `_asf`.
